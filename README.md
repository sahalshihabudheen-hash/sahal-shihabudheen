# Sahal Shihabudheen — Portfolio

> 🚀 Professional portfolio built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/sahalshihabudheen-hash/sahal-shihabudheen)

## ✨ Pages

| Page | Description |
|------|-------------|
| **Home** `/` | Hero with animated typing, particle system, about terminal card, skills grid |
| **Journey** `/journey` | Animated SVG roadmap with milestone markers, photo gallery, timeline |
| **Projects** `/projects` | Filterable project cards — NYRA Music, Movie Hub, SAI, bots, IoT |

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React + React Icons
- **Deployment**: Vercel

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 📦 Deploy to Vercel

```bash
npx vercel
```

Or connect the repo at [vercel.com](https://vercel.com)
